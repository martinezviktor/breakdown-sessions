# Breakdown Sessions

Sitio de [breakdownsessions.com](https://breakdownsessions.com). Es estático (HTML, CSS y JS, sin build).

Los episodios se leen en el navegador desde el feed de Captivate
(`https://feeds.captivate.fm/breakdown-sessions/`), así que al publicar uno nuevo aparece solo.

- `index.html`, `styles.css`, `app.js`: el sitio.
- `404.html`: lleva los enlaces viejos `/episode/<slug>` al episodio en la portada.
- `assets/`: logo, icono y la animación de la calavera del reproductor.
